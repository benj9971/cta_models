# CTA-style model versus published positioning

Run from the repository root:

```bash
python scripts/compare_reported_positions.py --output-dir output/position_comparison
python -m streamlit run dashboard/app.py
```

The script produces full-history and three-year three-panel charts, weekly comparison CSVs, conditional shock tables and a summary CSV for NYMEX platinum, COMEX gold and silver, LME nickel, zinc, aluminium and copper. Use `--markets COMEX_GC COMEX_SI` to generate only gold and silver. The dashboard's **Reported comparison** view displays these bundled research inputs. The chart uses model exposure (−100 to +100) and published net fund positions as a percentage of open interest on *separate axes*, then daily quoted price and close-only Wilder RSI(14) with 30/70 reference lines. LME reports select the **investment funds / total** bucket. The three US precious metals use CFTC disaggregated **managed money, futures only**. These categories, markets and position units differ. They are benchmarks for the model, not a measure of CTA holdings.

Full-history charts default to weekly display to improve readability: each week shows the last observed daily model score, quote and precomputed daily RSI. The most recent partial week is included. The weekly published report is unchanged. In the dashboard, choose Daily in the full-history Chart frequency toggle to see every session; in the script use `--full-frequency Daily`. Three-year charts and underlying daily calculations/exports are unchanged.

The model and weekly report are paired at the report's **position date** to describe contemporaneous positions. LME Friday positions usually publish Tuesday and the actual UTC timestamp is in the source CSV. CFTC Tuesday positions usually publish Friday; the historical export does not include exact release timestamps. Never use the paired report on its position date in a predictive test. Quotes match the position date or the latest earlier session within seven calendar days. Two nickel position weeks in March 2022 have no matched quote. Same-date correlation and sign agreement describe co-movement only; neither validates estimated CTA contracts nor establishes that positioning predicts future prices.

The scenario CSVs move **only the latest quote** by −10%, −5%, −3%, −1%, 0, +1%, +3%, +5% and +10%. `trigger_levels` also finds the nearest price within ±25% at which the frozen-snapshot score changes by ten points or crosses zero. The model holds previous prices and today's realized volatility/risk scale fixed; an actual shock would update volatility, execution prices and later signals. A ten-point threshold is a **model rebalance marker**, not a stop-loss, predicted CTA order, or executable futures price. Define an entry, instrument, sizing, loss budget, execution trigger (intraday versus daily close), gap/slippage and roll convention before computing a trade stop.
